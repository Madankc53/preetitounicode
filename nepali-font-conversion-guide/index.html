Legacy fonts vs Unicode: why Nepali text breaks

Old Nepali typing fonts such as Preeti and Kantipur reuse the English keyboard. When you press s the file stores the letter s, and the font draws it as क. Without that font installed, the same file shows plain English letters.

Unicode stores the real Devanagari characters, so the text looks the same everywhere and search engines, screen readers and phones can read it. That is why government sites, forms and Google need Unicode, and why print shops that still use Preeti sometimes need the opposite direction.

How to tell which font your text is in

  1. Check the font name in Word. Click inside the text and read the font box. Preeti or Kantipur means legacy text; Mangal, Kalimati, Noto Sans Devanagari or Nirmala UI means Unicode.
  2. Paste it into a plain text box. Legacy text turns into English letters with symbols like ] ; { | /. Unicode keeps real Devanagari letters.
  3. Look for Kantipur symbols. Characters such as ¥ ¨ ¬ µ Ô ‹ › appear in Kantipur text, not in Preeti.
  4. Boxes or question marks mean the right font is missing on your device, not that the text is wrong.
  5. Use the detector above for a quick guess, then confirm with a short sample in the converter.

Common problems and fixes

The output still looks like English letters

Either the text is already Unicode, or the converter is set to the wrong direction. If it contains real Devanagari, you do not need Preeti to Unicode; use Unicode to Preeti if you need the legacy form.

The output is Nepali but some letters are wrong

Usually the wrong font was chosen. Check the font name in the original file. If the text has Kantipur-only symbols, use the Kantipur converter.

A vowel sign or रेफ is on the wrong letter

The converter reorders ि and र् automatically. If one word still comes out wrong, send it through the contact page with the original keystrokes so the mapping can be fixed.

Numbers turned into joined letters

In Preeti, plain 0–9 are letter keys (for example 1 is ज्ञ). Turn on Keep 0–9 as English digits in the converter if your text has ordinary numbers. Nepali digits typed with Shift (!@#) convert to १२३.

Links and email addresses were damaged

The Preeti converter now keeps web addresses and email addresses unchanged. Other English words inside plain text cannot be told apart from Preeti keys. For Word files, upload the .docx: only runs set in Preeti or Kantipur are converted.

I see boxes or question marks after converting

The text is correct Unicode, but your device has no font for it. In Word choose Mangal, Kalimati or Noto Sans Devanagari.

Text copied from a PDF converts badly

PDF text can lose spaces or carry its own key order. Try a short line first. Scanned PDFs are pictures and need OCR, which this site does not offer.

My printer or DTP software needs Preeti

Convert your Unicode text with Unicode to Preeti, then set the Preeti font in the layout program. You can download the Preeti font to preview it.

Frequently asked questions

What is the difference between legacy Nepali fonts and Unicode?

Legacy fonts such as Preeti and Kantipur store Nepali as ordinary English keystrokes and only look like Nepali when the matching font is applied. Unicode stores real Devanagari characters, so the text stays correct in any Unicode Nepali font, on any phone, website or search engine.

How can I tell whether my text is Preeti or Kantipur?

Click the text in Word and read the font name in the font box. Pasted into a plain text box, both look like English letters and symbols such as ];{}|. Kantipur also uses a few extra symbols that Preeti does not. The detector at the top of this page gives a first guess, but the font name in the original file is the reliable answer.

Can one tool convert every Nepali font?

No. Every legacy font has its own key mapping, so each one needs its own table. This site converts Preeti and Kantipur. Fonts such as Sagarmatha and PCS Nepali are not supported here yet, and text in them is left unchanged in Word files.

Are Mangal and Kalimati Unicode fonts?

Yes. Mangal and Kalimati are Unicode Devanagari fonts, as are Noto Sans Devanagari and Nirmala UI. Text typed in them is already Unicode and needs no conversion. Use a converter only when you need the legacy Preeti form, for example for a print shop.

Why should I convert legacy text to Unicode?

Unicode text can be searched, copied, read aloud by screen readers, shown on phones without installing fonts, and indexed by Google. Legacy text appears to those systems as meaningless English letters.

Is the conversion perfect?

It is mapping-based, so common text converts reliably, but rare joined letters, unusual typing habits and mixed English text can need a manual fix. Always read names, numbers and dates against the original before you publish.
