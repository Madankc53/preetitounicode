Roman spelling is phonetic: aa = आ, ee = ई, sh = श, chh = छ, ksh = क्ष, gy = ज्ञ, M = ं, and {text} stays as typed. The Preeti output only looks Nepali after you apply the Preeti font. See the full typing scheme.

How to type Nepali in Preeti from English

  1. Type the Nepali word in English letters. Use aa for the long आ sound, for example nepaal (नेपाल) or namaste.
  2. Check the Nepali Unicode shown under the output. If a word is wrong, adjust the spelling (for example shikshaa gives शिक्षा).
  3. Copy the Preeti output, paste it into Word or your publishing software and set the font to Preeti.

Why go through Unicode?

Roman input is first converted to standard Nepali Unicode, then to Preeti. That keeps conjuncts, the short-i vowel (ि) and reph (र्) in the right place, so the Preeti text looks correct in the final document.

Frequently asked questions

Is Roman to Preeti accurate?

Roman Nepali spelling is ambiguous, so always check the Unicode line. Once the Unicode is right, the Preeti conversion follows fixed rules.

Can I type in Preeti directly?

You need the Preeti font and a Preeti keyboard layout for that. This page lets you type normal English letters instead.

Does it work offline or privately?

The conversion runs in your browser; nothing is uploaded.

How do I get Unicode only?

Use the Roman to Nepali typing tool.
